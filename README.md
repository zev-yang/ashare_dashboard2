# A股短期趋势监控（本地网页）

五个模块：① 避险板块 ② ETF资金 ③ 期指持仓 ④ 融资融券 ⑤ 均线，外加一个总览页。每个模块都给出 当日 / 本周 / 本月 统计。


## 0. 页面结构与自动更新
- **指数分析**（首页）：所有分析；顶部一行显示"日线最新到哪天 / 应有哪天"，落后会标黄并给出「去数据页更新」链接，可展开看每类数据的最新日期。
- **数据**：所有下载、上传、检查、数据源设置都在这里（更新全部、①–⑥ 单独下载、手动导入、导出 CSV、对齐检查、本地日线目录扫描、Tushare token）。
- **自动更新**（数据页第 4 节可开关/改时间）：
  1. 网页**保持打开**时，每 5 分钟自动检查一次：交易日、已过截止时间（默认 17:30）且核心数据落后，就自动更新并刷新页面；失败后隔 30 分钟才重试。
     前提是浏览器标签页没关、电脑没睡眠（浏览器休眠/丢弃标签页会停止检查）。首次打开页面也会立刻检查一次。
  2. 网页关着也想每天更新：用 Windows 计划任务运行 `auto_update.py`（工作日 18:00，非交易日/已最新自动跳过）。
     创建命令：`python auto_update.py --print-schtasks` 打印后复制到 PowerShell 执行；手动试跑 `python auto_update.py --force`。
     计划任务读不到终端环境变量，token 请在数据页「保存到本地文件」。
  3. 所有更新（手动、自动、计划任务）都会记录到 `data/cache/logs/update.log`，数据页可看。
- 融资/ETF份额披露常晚一天，新鲜度判断里允许这两类落后 1 个交易日。

## 1. 安装与启动（Windows / Anaconda PowerShell）
```powershell
cd ashare_dashboard
pip install -r requirements.txt
streamlit run app.py
```
浏览器会自动打开 http://localhost:8501 。

## 2. 先看效果（模拟数据）
```powershell
python make_demo_data.py
$env:ASHARE_DEMO=1; streamlit run app.py
```
演示数据全是随机数，仅用来熟悉界面。

## 3. 接入真实数据（推荐：全部自动下载）
页面最上方 **「🔄 更新全部数据」** 一个按钮会依次执行下面五项；侧边栏也可以单独点：

| 按钮 | 内容 | 落地格式（一个交易日一行） |
|---|---|---|
| ① 融资融券 | 沪深交易所个股明细（含成分股名单） | `margin.csv`：date, code, rz_balance, rz_buy, rz_repay |
| ② 期指 | 中金所前20会员持仓排名 + 合约日行情 | `cffex_rank.csv`、`cffex_daily.csv` |
| ③ 四大指数日线 | 000300/000016/000905/000852（对应 IF/IH/IC/IM） | `px/代码.csv`：date, open, high, low, close, volume, amount |
| ④ ETF/板块个股日线 + ETF份额 | 程序里用到的 ETF、板块个股；可选成分股 | 同上；`etf_shares.csv` |
| ⑤ 外资代理 | A50、USDCNH、AH溢价(HSAHP)、恒生、FXI、KWEB | `proxy_daily.csv`：date, symbol, open, high, low, close, volume |

要点：
- **颗粒度对齐**：所有"按日"数据都以交易日历为准逐日抓取，只抓交易日，已有的日期不重复抓；再次点击只做增量（并往前补 10 个交易日的漏洞）。
- 侧边栏 **「数据对齐检查」** 以沪深300日线为基准，列出每个数据集的缺失日期、落后天数。外资代理保留各市场原始交易日（A股休市而美股开市等情形），对齐留到分析阶段处理。
- 下载的日线放在 `data/cache/px/`；若你本地 `data/daily/` 里已有同代码日线，**以本地为准，只用下载数据补本地缺的最新几天**。本地成交额按 `ASHARE_AMOUNT_UNIT` 换算，下载的已是"元"。
- 侧边栏「导出标准化 CSV」可把任何数据集按程序格式导出。
- 自动下载失败时：到官网下载文件，用侧边栏「手动导入」上传。

也可以仍用你自己下载的日线：放进 `data/daily/`（文件名含6位代码；列名中英文均可；成交额不是"元"时设 `$env:ASHARE_AMOUNT_UNIT=10000`）。


## 3b. 使用 Tushare（推荐，更快更稳）
1. `pip install tushare`
2. 配置 token（任选一种；**不要把 token 提交到 GitHub**，`.gitignore` 已排除 `tushare_token.txt`）：
   - 环境变量：`$env:TUSHARE_TOKEN="你的token"`
   - 或在网页侧边栏「数据源 / Tushare token」里粘贴，点「保存到本地文件」
3. 数据源选「自动」时：有 token 就优先用 Tushare，失败再回退免费源；也可选「仅免费源 / 仅 Tushare」。
4. **⑥ 本地个股日线批量更新**：把你日线目录里每只股票补到最新，格式与旧文件一致（date,open,high,low,close,volume,amount,code,name），追加写入。
   速度提升来自"按交易日取全市场"：缺 N 个交易日只需 N 次调用（逐只则要上千次）。每分钟调用上限默认 42（你的账号 daily 是 50 次/分）。
5. Tushare 同时提供融资融券明细、中金所持仓排名/日行情、ETF份额、指数成分股、离岸人民币等，已接入对应下载按钮。


## 3c. 指数文件必须放 index 子目录（重要）
指数代码 000016（上证50）、000905（中证500）、000852（中证1000）同时也是个股代码（深康佳A、厦门港务、石化机械）。
为避免把个股日线当成指数，程序对这四个指数代码**只认**：
- 日线目录下名字含 `index` / `idx` / `指数` 的子目录里的文件（如 `stock_data_all/index/000905.csv`）；
- 自动下载的 `data/cache/px/index_代码.csv`。

放在日线目录根部的 `000905.csv` 会被忽略（诊断表里会标 ⚠️ 已忽略）。⑥ 批量更新也不会往这几个同号文件里追加数据。

## 3d. 怎么核对计算结果
- 均线页有「判定依据」列，写明每个状态是怎么判出来的（收盘、MA5/20/60 的具体数值和比较）。
- `python verify_calc.py [代码] [日期]`：不经过网页，直接读日线手工复算均线和状态，把最近 6 天收盘列出来，和行情软件逐个核对。
- 总览页顶部会对明显异常报红：指数单日变动超过 12%、期货点位与指数点位相差 20% 以上等。

## 4. 配置
`config.py`：板块成分股、ETF代码、关注席位、"空单性质"阈值。改完刷新网页即可。

## 5. 已知限制（务必看）
- **联网下载未用真实网站实测**（开发环境访问不了这些网站）；下载流程已用模拟接口完整测过。真实接口若改版，日志会写明哪一步失败，把日志发回来即可。
- A50 等外资代理来自 akshare 的日线（新浪外盘/东财），无法单独拆出"夜盘"时段；夜盘口径留到分析阶段再定。
- 北向每日数据已停止披露（2024-08-19 起），没有使用；由 ⑤ 的外资代理指标替代，分析待下载后再做。
- "空单性质"是启发式规则，页面内置了历史检验；ETF 份额历史目前只自动抓沪市。
- 成分股用当前名单，未还原历史调样。
